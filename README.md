## 🚀 Features Implemented

- **Responsive Flutter UI:** Developed clean and responsive user interfaces for mobile devices.
- **Multi-Vendor Support:** Vendors can list and manage products.
- **State Management with Riverpod:** Efficient app state management across all screens.
- **Backend API with Node.js & Express:** Secure backend for authentication, orders, and products.
- **MongoDB Database Integration:** Scalable CRUD operations for users, products, and orders.
- **Real-Time Updates:** Notifications for orders and promotions.
- **Deployment Ready:** Configured app and backend for deployment.
